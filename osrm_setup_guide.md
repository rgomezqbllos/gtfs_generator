## Sintaxis actual del comando (3 argumentos obligatorios)

```bash
npm run osrm:setup -- <ciudad> <puerto> "<url-geofabrik>"

# Ejemplo:
npm run osrm:setup -- bogota 5001 "https://download.geofabrik.de/south-america/colombia-latest.osm.pbf"
```
